# 用户画像库（阶段 3 双视角详版）

测试即扮演。每个画像 = 一组具体动作 + 观察点。不必每次全用——按项目的功能类型挑最相关的，但**日常与刁钻两遍都必须有**。

## 第一遍：日常用户（The Regulars）

### 🐣 新手小白
什么都不懂，不看文档直接上手。
- 空输入直接回车提交；输入"你好"这种答非所问的内容
- 乱点所有能点的东西，反复前进后退
- 观察点：空输入是否被优雅拦截？错误提示能不能看懂？会不会点出 500？

### 🚴 熟练用户
日常重度使用，追求效率。
- 跑完整工作流（如：创建 → 编辑 → 查询 → 删除，一条链走到底）
- 连续快速操作、短时间内重复同一动作、快捷键
- 输入真实量级的数据（一次 50 条、一页 100 行）
- 观察点：链路中间断了能否恢复？连续操作会不会丢状态？

### 👨‍💼 管理员 / 配置者
碰权限和配置的人。
- 改配置后功能是否生效、改错配置是否被拦截
- 权限边界：普通身份访问管理入口会怎样
- 观察点：越权是否被拒？配置回滚是否可用？

### 🌍 国际用户
- 中文、英文、emoji（🎉🚀）、日文、RTL 文本（阿拉伯语/希伯来语）
- 时区与日期格式（2026-10-30 vs 10/30/2026 vs 30.10.2026）、跨日边界操作
- 观察点：编码乱码？日期解析错？emoji 截断或报错？

### 📱 弱网 / 小屏用户
- 很窄的窗口宽度、边滚动边操作
- 提交后立刻刷新页面、操作中途返回
- 观察点：重复提交产生脏数据？中途退出状态错乱？

## 第二遍：刁钻用户（The Adversaries）

> 授权边界：以下动作仅针对用户自己的/明确授权的本地目标，目的是验证防御，不是攻击演示。

### 🎯 边界猎人
- 数值：`0`、`-1`、`1`、最大值（如 2147483647）、超最大值、极小数、非数字（"abc"、空串）
- 集合：空数组 `[]`、单元素、重复元素、null/undefined/None
- 字符串：空串、纯空格、单字符
- 日期：1970-01-01、9999-12-31、2月30日、闰年 2/29

### 💉 注入玩家
- SQL 注入：`' OR '1'='1`、`'; DROP TABLE --`
- XSS：`<script>alert(1)</script>`、`<img onerror=...>`
- 命令注入：`; rm -rf /`、`$(reboot)`、`` `id` ``
- 路径穿越：`../../etc/passwd`、`..\..\windows`
- JSON/YAML/模板注入：`{{7*7}}`、`$__import__`
- 观察点：被正确转义/参数化/拦截 = PASS；原样执行或回显未转义 = 严重 bug

### 🔨 暴力操作者
- 双击/三击提交按钮（并发重复请求）
- 提交后秒刷新、秒返回
- 同一账号多端同时操作同一资源
- 观察点：重复创建？数据覆盖丢失？锁/幂等缺失？

### 🐍 超长输入狂
- 1 万 / 10 万字符的文本字段
- 深层嵌套 JSON（1000 层）
- 巨大上传文件、超长 URL（8KB+）
- 观察点：截断不告知？崩溃？超时无响应？界面卡死？

### 🌀 状态错乱者
- 跳过步骤直接访问后面的 URL / API（拿到内部状态）
- 带过期/伪造的 token 调接口；重放修改过的旧请求
- 修改前端隐藏字段（价格、数量、user_id）再提交
- 引用不存在的 id、已删除的资源
- 观察点：服务端是否独立校验，还是信任了客户端？

### 🧹 数据洁癖
- 文件名/字段用特殊字符：空格、`#`、`%`、中文、emoji、不可见字符（零宽空格 U+200B）
- 同名冲突（两个同名文件/条目）、全空格名称
- 观察点：保存后能否原样读回？排序/搜索对特殊字符是否正常？

### ♿ 辅助功能用户（v1.0 新增）

- 全程只用键盘（Tab / Shift+Tab / Enter / Esc）走完主流程
- 开读屏、200% 缩放、只开高对比度/灰度模式
- 观察点：焦点是否可见且不被吸顶元素遮住？错误是否被播报？状态是否**只靠颜色**表达？目标是否小到点不中？

### 🏢 多租户 / 协作用户（v1.0 新增）

- A 租户用户尝试访问 B 租户的资源、邀请、报表
- 同一资源两个成员同时编辑；管理员被降级后旧会话是否仍有权
- 观察点：租户隔离、并发编辑冲突、权限变更即时生效

### 🔓 越权者（v1.0 新增 · 对应 OWASP API1/3/5）

- 把 URL 里的 `id` 换成别人的、遍历连续 ID
- 请求体偷偷塞 `role:"admin"`、`user_id:他人`、`price:0`（批量分配）
- 普通账号调 `/admin/*`，把 `GET` 换成 `DELETE`
- 观察点：服务端是否独立校验归属与属性白名单（详见 `security-testing.md` §1）

### 🔁 幂等破坏者（v1.0 新增）

- 双击提交、超时后重试、重复回调、并发改同一资源
- 观察点：重复创建？库存/余额双花？后台任务重复执行结果是否一致？

> 提示：日常 7 个 + 刁钻 8 个画像不必全用。按 `dissect.md` §8 的能力层路由挑最相关的，**但日常与刁钻两遍都必须有**。

## 判 bug 标准（两遍通用）

任一命中即记 bug：

1. 崩溃、异常退出、未捕获报错（500 / 堆栈裸奔 / 进程挂掉）
2. 报错信息人类看不懂、误导，或该报错时不报错（静默失败）
3. 数据损坏、状态错乱、丢数据
4. 安全漏洞（注入生效、越权、敏感信息泄漏）
5. 明显不符文档宣称的行为

严重级别：**严重**（数据损坏/安全/崩溃）＞ **一般**（功能错误但有绕过）＞ **轻微**（体验/提示问题）。
