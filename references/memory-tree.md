# 记忆树完整规范（阶段 0 / 阶段 4 详版）

记忆树是本技能省 token 与接力的核心机制。位置固定在**目标项目根目录** `.test-memory/`（跟项目走，换 agent、换会话都在）。

## 目录结构

```
<目标项目>/.test-memory/
├── tree.md          # 地图+索引（<100 行）：画像、命令速查、模块树、已知问题、下次待办
├── lessons.md       # 项目级经验教训
├── runs/            # 每次运行的详细记录（保留最近 10 份）
│   ├── 2026-10-28-1-login.md
│   └── 2026-10-30-1-payment.md
└── tmp/             # 临时探针文件，测试结束删除
```

初始模板：`assets/tree-template.md`。

## tree.md 各区规则

1. **项目画像**：栈、入口、依赖。只在首次或技术栈变化时更新。
2. **命令速查**：所有真实跑通的命令（启动、测试、构建），含工作目录与端口。这是接力时最值钱的部分——**宁可多记一条命令，不可下次重新试错**。
3. **模块树**（"树"的本体）：根 = 项目，枝 = 功能模块，叶 = 测试点。每片叶带状态标记 + 日期 + 指向 runs/ 的指针。模块新增随测试推进补充；模块已稳定（连续两次全绿）可折叠为一行。
4. **已知问题**：BUG# 编号、一句话描述、状态（未修复/已修复待回归/已关闭）。已关闭的保留一行供追溯，细节留在 runs/。
5. **下次待办**：下次测试直接从这里开工。

状态标记：`✅` 通过 ｜ `🐛` 有 bug ｜ `⬜` 未测 ｜ `◐` 部分测试 ｜ `🔥` 阻塞

## runs/ 运行记录格式

```markdown
# 2026-10-30-1 支付模块深测
环境：Win11 / Git Bash / Node 20.x　范围：P0 支付 + P1 退款
## 测试点结论
| # | 测试点 | 视角 | 结论 | 证据/复现 |
|---|---|---|---|---|
| 1 | 创建订单正常流 | 日常 | ✅ | curl POST /api/order → 200 |
| 2 | 负数金额 | 刁钻 | 🐛 BUG#4 | `amount: -1` 被接受，余额反向增加 |
## 发现的 bug
BUG#4：负数金额未校验。复现：curl -X POST -d '{"amount":-1}' ... 实际：200 且余额+1
## 跑通的命令
npm run dev  # 端口 3000，启动约 3s
curl -s -X POST http://127.0.0.1:3000/api/order -H "Content-Type: application/json" -d '{"amount":-1}'
## 教训（同步进 lessons.md）
金额校验只在端做，服务端裸奔
```

## 更新规则

- **一次运行一个新文件**（`YYYY-MM-DD-N-<slug>.md`，同日第 N 次），不改写旧记录——历史是资产
- 同日续测同一范围可追加到当天的文件，但跨日必开新文件
- tree.md 每次运行结束**必须**更新（哪怕只改一行日期）
- runs/ 超过 10 份时删最旧的（先确认其 bug 都已闭环）

## lessons.md 格式（项目级）

```markdown
# 项目教训
- [校验] 金额校验只在端做，服务端测试必带负数/超长用例 — 应用：所有金额接口先打边界
- [环境] Windows 下 npm run dev 端口偶发占用，用 PORT=3001 备用 — 应用：启动失败先换端口
```

一行一条：`[标签] 教训 — 应用：怎么用`。标签建议：校验/环境/工具/流程/安全。

## v1.0 新增字段（保持 <100 行的前提下加，不加重则不加）

**头部元信息**追加技能版本与能力层，便于升级后判断旧记录是否仍适用：

```
> 更新：<YYYY-MM-DD> ｜ 运行次数：<N> ｜ 技能版本：v1.0.0 ｜ 能力层路由：API+安全+性能
```

**已知问题**表增加严重度与回归标记（与 `quality-gates.md` §2 对齐）：

```
| 编号 | 严重度 | 一句话 | 状态 | 回归用例 |
|---|---|---|---|---|
| BUG#4 | S1 | 负数金额未校验 | 已修复待回归 | `curl -d '{"amount":-1}'` |
```

**下次待办**区分三类，避免接力时把"待修"当"待测"：

```
- [ ] 回归：BUG#4 / BUG#7（附最小复现命令）
- [ ] 待测：退款流程、导出（P0）
- [ ] 阻塞：本地 Postgres 起不来 → 试 testcontainers（🔥）
```

**跨轮指标**（可选，写在头部一行）：`覆盖 P0 x/y ｜ 未闭环 S1 n ｜ p95 ___ms ｜ 变异得分 ___`。指标必须写清分子/分母与口径，不许只报一个漂亮数字。

> 纪律不变：tree.md 只放状态与指针，细节全沉 runs/。新增字段若把树撑过 100 行，优先合并已稳定模块，而不是删掉证据。

## 省 token 三律

1. tree.md < 100 行——细节沉到 runs/，树上只留状态与指针
2. 读记忆树优先于重新探索——画像/命令速查直接信，除非现场跑不通
3. 稳定模块折叠——连续两次全绿的模块合并成一行，叶子细节留在 runs/ 里
