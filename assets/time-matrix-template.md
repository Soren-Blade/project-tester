# 时间与时区正确性测试矩阵（R-13）

> 用法：复制本文件到 `<目标项目>/.test-memory/time-matrix.md`，逐行填「实测值 + 证据位置 + 结论」。
> 规则：**没有证据的位置不得写 PASS**；没测的行写 `未测`，不适用的行写 `不适用：<理由>`。
> 配套：`references/time-correctness-testing.md`、`scripts/time-audit.py`。

## 3. 盲区与降级声明

| 盲区 | 原因 | 影响 | 降级结论 |
|---|---|---|---|
| 未做时钟回拨实测 | 无 libfaketime / 不能改系统时钟 | 超时与限流在时钟回拨下的行为未知 | R-13 降级为「部分覆盖」 |
| 未覆盖 fold 日调度 | 环境无法注入时间 | 重复执行风险未知 | 不得写「DST 安全」 |
| 无 tzdata | 运行环境缺数据 | 无法计算 gap/fold | `BLOCKED: 无 tzdata` |
| 单时区内部工具 | 无跨时区用户 | 影响面小 | 「不适用：单时区，未做跨时区验证」 |
