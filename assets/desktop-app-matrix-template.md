# 桌面应用边界矩阵（模板 · R-26）

> **用法**：复制到被测项目（建议 `.workbuddy-ai/desktop-matrix.md`），逐格填「做 / 未做 + 证据位置」。空着写「未做」，不得写「基本可用」。
> **配套**：`references/desktop-app-testing.md`（判据）、`scripts/desktop-audit.py`（静态扫描与用例）。
> **本模板自身不产出结论**：结论由填写人基于证据给出，PASS 必须能指回具体行。

## §1 制品与分发

| 项 | 填法 |
|---|---|

| 打包工具与版本 | electron-builder / Electron Forge / tauri-cli，版本号 |
| Electron / Tauri 版本 | 如 `Electron 32.x` / `Tauri 2.x` |
| 代码签名 | 有 / 无；证书类型（Developer ID Application / EV）；未签名写「未签名」 |
| 公证（macOS） | 已公证 / 未公证 / 不适用（非 macOS） |
| 自动更新 | 更新器实现、更新源域名、是否 https、pubkey 是否存在 |
| 灰度/分发渠道 | 官网 / 商店 / 内测通道；是否分阶段放量 |

## §10 结论

- **总判定**：PASS / FAIL / 待确认（只能三选一）
- **未验证项**：逐条列，含原因（无签名环境 / 无第二平台 / 无 GUI 会话 …）
- **降级说明**：dev 模式 / 只测允许路径 / 无回滚记录，分别降了什么
- **不得声明**（逐条勾选，出现即判结论无效）：
  - [ ] 不得把 dev 模式结论写成「发布形态通过」
  - [ ] 不得把「签名有效」写成「应用安全」
  - [ ] 不得在只测允许路径时写「边界成立」
  - [ ] 不得在一个平台通过时写「跨平台已验证」
  - [ ] 不得把静态扫描 0 命中写成「无风险」
  - [ ] 不得在没有降级拒绝证据时写「更新可信」
