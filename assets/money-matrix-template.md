# 金额与账务正确性测试矩阵（R-15）

> 用法：复制本文件到 `<目标项目>/.test-memory/money-matrix.md`，逐行填「实测值 + 证据位置 + 结论」。
> 规则：**没有证据的位置不得写 PASS**；没测的行写 `未测`，不适用的行写 `不适用：<理由>`；拿不到真实账本时**不得**写「账务正确」。
> 配套：`references/money-correctness-testing.md`、`scripts/money-audit.py`。

## 0. 基本信息

| 项 | 值 |
|---|---|
| 项目 / 版本 | |
| 测试日期 | |
| 涉及币种 | 例：`CNY`、`USD`、`JPY`、`KWD`；**必须写出各币种 exponent** |
| exponent 来源 | ISO 4217 / 支付渠道文档 / 代码常量；写清是哪一种 |
| 舍入模式 | half-even / half-up / 截断；写清发生在哪一层（展示 / 结算 / 退款） |
| 金额存储类型 | 整数最小单位（`BIGINT` cents）/ `DECIMAL(p,s)` / 浮点（命中即风险） |
| 计价与账本来源 | 订单库 / 支付渠道流水 / 银行对账单；注明可访问性 |
| 结论 | PENDING / PASS / FAIL / BLOCKED(理由) |

## 1. 六个面 × 用例

## 3. 盲区与降级声明

| 盲区 | 原因 | 影响 | 降级结论 |
|---|---|---|---|
| 无真实支付渠道沙箱 | 无密钥/无商户号 | 渠道侧舍入与手续费未知 | R-15 降级为「部分覆盖」，不得写「金额正确」 |
| 无银行/渠道对账单 | 只有应用库 | 只能证明库内自洽 | 只能写「账本内部平衡」，不得写「对账通过」 |
| 只有单币种 | 业务未开通多币种 | 0/3 位小数未实测 | 「不适用：仅 CNY；多币种未测」 |
| 无并发压测环境 | 单机/无限流 | 超卖与重复扣款未实测 | 不得写「并发安全」 |
| 舍入模式未写进契约 | 产品未定义 | 无法判定 0.005 该进该舍 | `BLOCKED: 舍入模式未定义` |
