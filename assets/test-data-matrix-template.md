# 测试数据管理矩阵（TDM）模板

> 配套 `references/test-data-management.md`（R-11）。每条结论填证据或「不适用 / 待确认」，**不得**用"用了生成器"冒充"数据已脱敏"。

## 0. 速览

| 项 | 值 |
|---|---|
| 数据来源 | 合成生成 / 脱敏生产抽取 / 子集拷贝 / 全量合成（选一，附命令） |
| 生成器与种子 | 工具名 + 版本 + `--seed`（可复现必备） |
| 是否含生产 PII | 是（须脱敏）/ 否（写"未使用生产数据"） |
| R-11 结论 | PASS / 待确认 / 不适用 |

## 1. 数据来源与制备证据

| 维度 | 测试点 | 方法 / 命令 | 证据（命令+输出原文） | R-11 结论 |
|---|---|---|---|---|
| 数据来源声明 | 合成 or 脱敏 or 子集 | 生成/掩码/抽取命令原文 + 退出码 | `<paste>` |  |
| 合成生成 | 字段/类型/分布/边界覆盖 | `scripts/test-data-gen.py generate --count 100 --seed 42` | `<paste>` |  |
| 脱敏生产抽取 | 抽取命令 + 掩码命令 | `mask --fields email,phone,name` 原文 + 退出码 | `<paste>` |  |
| 数据即代码 | fixtures/factories/seeds 入库 | 仓库路径 + 版本化声明 | `<path>` |  |

## 2. 可复现证据（确定性种子）

| 维度 | 测试点 | 方法 | 证据 | R-11 结论 |
|---|---|---|---|---|
| 可复现 | 同种子两次生成逐字节一致 | 生成两次取 hash 比对：`sha256 out1 == sha256 out2` | `seed=42: hash1=... hash2=... 一致=✅` |  |
| 无种子声明 | 声称"可复现"但无种子 | 查生成命令是否带 `--seed` | `有/无` | 不适用 / 待确认 |

> 无种子或无法比对 → 写「数据可复现：待确认」，**不得**判 PASS。

## 3. PII 脱敏证据

| 字段 | 原始（脱敏前） | 掩码后 | 残留核查（扫描仍含明文？） | 人工复核 | R-11 结论 |
|---|---|---|---|---|---|
| email | `<a@b.com>` | `<a***@b.com>` | 扫描结果：未发现明文邮箱 ✅ / 发现 N 处 ⚠️ | 通过 / 待确认 |  |
| phone | `<13800001234>` | `<****1234>` | 扫描结果：未发现明文手机 ✅ / 发现 N 处 ⚠️ | 通过 / 待确认 |  |
| name | `<张三>` | `<张**>` | 扫描结果：未发现明文姓名 ✅ / 发现 N 处 ⚠️ | 通过 / 待确认 |  |

> 掩码只替换**显式列出**的字段；残留核查发现明文 PII 即降为「待确认」。用了 `scripts/test-data-gen.py mask` **不**等于"数据已脱敏 / 无 PII 泄漏"。

## 4. 子集完整性证据（如做了子集）

| 维度 | 测试点 | 方法 | 证据 | R-11 结论 |
|---|---|---|---|---|
| 外键完整 | 悬空外键数 = 0 | 抽取后查 `LEFT JOIN ... WHERE fk IS NULL` 计数 | `悬空外键 = 0` |  |
| 引用一致 | 主表替换后从表同步替换 | 抽查关联记录是否一致假值 | `<paste>` |  |
| 体积 | 子集占比 / 行数 | 子集行数 / 生产行数 | `<n>/<N>` |  |

> 未做子集、用全量合成 → 写「不适用：使用全量合成，无子集」。

## 5. 无生产数据声明

- [ ] 测试环境连接串不含生产 host：`<声明或连接串（脱敏）>`
- [ ] 临时含 PII 数据已退役：`<已清理 / 不适用：纯合成>`
- [ ] 未直连生产库做测试：`<是 / 不适用>`

## 6. 不适用声明（当本项目无测试数据维度时）

> 纯静态算法库 / 无数据依赖 / 纯离线脚本 → 写「**不适用：无测试数据维度**」，**不得**写"测试数据可信 / 数据已脱敏 / 数据可复现"。部分证据缺失 → 写「测试数据存在 N 处缺口，R-11 降级为待确认」，**不得**把"用了生成器"冒充"数据已脱敏"。

## 7. 诚实边界

- `scripts/test-data-gen.py` 只做生成/掩码/校验，**不裁决**"无 PII 泄漏""合规通过""数据可用"。
- 掩码是启发式（保留格式、替换主体），**不保证**覆盖全部 PII、**不保证**不可逆。
- 声称"测试数据已脱敏 / 合成数据无 PII 泄漏 / 数据可复现"必须附本模板 1~5 节证据，否则降级为「待确认」。
